# Calder: chapter and ending card briefs (for ChatGPT)

These are concept briefs, not finished art. Each card is **320 × 180 px, no people** (a figure seen from far behind is fine where noted). Start from the named place file in `art/places/` (the "base") and change the time, weather and season to fit the moment. Keep the Calder palette: violet night skies with coral city glow, teal painted brick against red brick, amber sodium light, and cyan hospital light. Save each card as `art/cards/chNN.png` or `art/cards/end_<id>.png`, and the game uses it automatically.
